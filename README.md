# Claudia Partner Docs

Claudia PartnerのAPI・MCP公開ドキュメントの配信用ファイルです。

https://mxd2024.github.io/claudia-partner-docs/

API接続先・顧客情報・資格は含みません。

## ファイルの整合を確認する

manifest.jsonに、各ファイルのSHA-256を記載しています。取得したv0.7/openapi.jsonは、manifest.jsonのfilesにあるv0.7/openapi.jsonの値と照合できます。source_openapi_sha256は、公開用に加工する前のOpenAPIの値です。

## 誤記・ご質問

ドキュメントの誤記は、このリポジトリのIssuesへお寄せください。接続の相談は、ドキュメントの「接続情報の依頼窓口」をご覧ください。顧客の接続先や資格は、Issueに書かないでください。
