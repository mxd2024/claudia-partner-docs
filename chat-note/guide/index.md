# Chat Note の概要

Claudia Partner Chat Note（以下、Chat Note）は、社内の会話と記録を、部署やケースごとのカテゴリに残すサービスです。ケースとは、案件・工事・依頼など、会社が番号で管理する仕事の単位です。Claudia Partner の基盤（社員・役割・ケースを管理するしくみ）と同じアカウントでサインインして使います。

## 主な機能

| 機能 | 内容 |
|---|---|
| スレッド | テーマごとの会話です。返信・引用・編集ができます |
| チャット | 1対1、または複数人のチャットです |
| ノート | 見出し・表・箇条書きを使って記録を作成します。コメントを付けられます |
| 添付 | 画像・動画・PDF・Office ファイルを添付できます（1ファイルあたり50 MBまで） |
| 返信通知 | 自分の投稿に返信や引用があると通知します |
| 検索 | 閲覧できるカテゴリのスレッドとノートを検索します |

## 構成

Chat Note のつながり （URL と利用できるカテゴリは、環境ごとに異なります） A. 社員の利用 PC ではアプリの画面に埋め込んで使い、スマートフォンでは Chat Note を直接開いて使います。 社員のブラウザー PC・スマートフォン Claudia Partner のサインイン Chat Note スレッド・チャット・ノート B. アプリのサーバーからの利用 アプリのサーバーが、社員のアクセストークンを付けて、その社員として読み書きします。 アプリのサーバー（BFF） 同じサーバーの中から 社員のアクセストークン Chat Note の API カテゴリ・スレッド・ノート C. 基盤からの取り込み 閲覧権限は、基盤の役割とケースの担当者から設定されます。 Claudia Partner の基盤 役割・ケースの担当 1日1回の取り込みとサインイン時 Chat Note のカテゴリ 部署のカテゴリ・ケースのカテゴリ

| 項目 | 内容 |
|---|---|
| サインイン | Claudia Partner のサインインIDでサインインします。2要素認証も基盤と同じです |
| 利用する端末 | PC では、社員用アプリなどの画面に Chat Note を埋め込んで使えます。スマートフォンとタブレットでは、ブラウザーで Chat Note の URL を開いて使います |
| 閲覧権限 | 基盤の役割とケースの担当者をもとに、自動で設定されます。詳しくは[カテゴリと閲覧権限](access.md)を参照してください |
| 管理画面 | カテゴリの作成、権限の設定、カテゴリ名の変更、タグの数の変更、スレッドの移動ができます。詳しくは[管理画面での設定](admin.md)を参照してください |
| アプリとの連携 | アプリの画面への埋め込みと、アプリのサーバーから使う API があります。詳しくは[アプリの画面への埋め込み](embed.md)と[サーバー用 API](server-api.md)を参照してください |

## 対象外の機能

- Chat Note には AI の機能はありません。Chat Note が会話の内容を外部の AI サービスに送ることもありません。
- アプリで AI（要約・下書きなど）を使うかどうか、どの AI サービスを使うかは、アプリを利用する会社で決めます。費用もアプリを利用する会社の負担です。
- Claudia Partner は、お客様の AI サービスの API キーをお預かりしません。
- Claudia Partner が提供する別の AI の機能をご希望の場合は、Claudia Partnerサポートにご相談ください。
- 音声通話とビデオ通話はありません。
- カレンダーはありません。予定とタスクは基盤の予定・タスクの表で管理し、アプリの画面に表示します。
