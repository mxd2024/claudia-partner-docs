# 管理画面での設定

部署の場所とケースの場所は、基盤の役割とケースの担当者から、自動で作られます（ケースの場所は、そのケースを使える人が初めて開いたときに作られます。[場所と、使える人](access.md)）。それ以外の設定は、Chat Note の管理画面で行います。たとえば、社外の人（取引先・外注先など）ごとの場所や、決まった人だけの場所を作る、場所の名前や札の数を変える、スレッドを別の場所へ移す、といった設定です。

## 受け持ち

| もの | 受け持ち |
|---|---|
| 管理画面での設定（場所を作る・使える人を決める・名前を変える・札の数・スレッドを移す）と、その内容 | 会社の管理者 |
| 上の設定の相談と、ご依頼を受けての代行 | Claudia Partnerサポート |
| Chat Note のしくみ（サインイン、部署とケースの場所を自動で作る決まり、更新、バックアップ） | Claudia Partner |

- 管理画面での設定の内容は、会社で決めます。Claudia Partnerサポートが代わりに設定したときも、内容は会社の管理者が決めたものとして扱います。
- **管理画面を使えるようにする手続きは、Claudia Partnerサポートにお問い合わせください。** 使えるようになるまでは、このページの設定は、ご依頼を受けて Claudia Partnerサポートが代わりに行います。

## 管理画面の開き方と、呼び方

管理画面は、Chat Note の住所の後ろに `/forum/admin` を付けて開きます（例：`https://（Chat Note の住所）/forum/admin`）。管理画面では、Chat Note の画面と呼び方が違います。

| Chat Note の画面 | 管理画面 |
|---|---|
| 場所 | カテゴリ |
| スレッド・ノート | スレッド（ノートも、管理画面ではスレッドとして並びます） |
| 札 | タグ |
| 使える人 | 権限 |

## 場所を作る

社外の人ごとの場所や、役員だけ・承認用など決まった人だけの場所は、次の手順で作ります。

1. 管理画面の「管理」›「カテゴリ」を開き、「カテゴリを追加」を押します。
2. 「カテゴリ名」に場所の名前を入れます。
3. 「(任意)親カテゴリ」で、どの場所の下に並べるかを選びます。いちばん上に並べるときは「(なし)」を選びます。ここを選ばないと、次の 4 で選んだ場所と同じ親の下に入ります。
4. 「(任意) 設定を複製するカテゴリ」で、部署の場所を1つ選びます。新しい場所の使える人は、選んだ場所の使える人と同じになります。部署の場所は、その部署の人と全部署を見る役割の人だけが使える、閉じた設定です。
5. 作ったら、すぐに次の「使える人を決める」で、使える人を決めます。

**「設定を複製するカテゴリ」を選ばずに作った場所は、初めは、サインインした全員（社外の人も含みます）が見られる設定になっています。** 必ず、次の「使える人を決める」の 4 で、決めた人・グループ以外の行の印を外してください。

## 使える人を決める

1. 管理画面の「管理」›「権限」を開き、「権限を設定」で場所を選びます。
2. 人を足すときは、「ユーザー」の欄の「ユーザーを追加」で、その人を選びます。**人は、一度 Chat Note にサインインしたあとで、選べるようになります。** まだの人には、先にサインインしてもらってください。グループを足すときは、「グループ」の欄の「グループを追加」で選びます。
3. 足した行に、使える範囲の印を付けます。

   | 使える範囲 | 印を付ける権限 |
   |---|---|
   | 見る | 「カテゴリを検索」「カテゴリにアクセス」「スレッドにアクセス」 |
   | 書く（ノートを作るときも） | 上に加えて、「スレッドを作成」「スレッドに返信」「スレッドにタグ付け」 |
   | 投稿を整理する・スレッドを移す | 上に加えて、「モデレーション」 |

4. 決めた人・グループ以外の行は、印をすべて外します。特に「登録済みユーザー」（サインインした全員）の行に印が残っていると、だれでも見られます。
5. 「変更を保存」を押します。

- 社員全員を足すときは、グループ「chatnote-employees」を選びます。社外の人は、このグループに入りません。
- 部署ごとのグループの名前は、部署の場所を初めに作ったときの名前です（例：営業）。場所の名前をあとで変えても、グループの名前は変わりません。
- 取引が終わった社外の人は、その人の行の印を外して保存します。その人が入っているグループの行に印があるときは、その人はグループを通して見えたままになります。外し忘れると、その場所が見えたままになります。

## 場所の名前を変える

1. 管理画面の「管理」›「カテゴリ」で、その場所の「カテゴリを編集」を開きます。
2. 「カテゴリ名」を変えて、「変更を保存」を押します。

- 部署の場所の名前も、ここで変えられます。基盤の写しで、元の名前に戻ることはありません。
- ケースの場所の名前は「ケース番号 件名」です。基盤で件名が変わると、次の写し（1日1回）のあと、またはその場所を次に開いたときに、新しい件名に変わります。

## 1件に付けられる札の数

場所ごとに、1件のスレッドに付けられる札の数を決められます。

1. 管理画面の「管理」›「カテゴリ」で、その場所の「カテゴリを編集」を開きます。
2. 「Tags per topic」の「最大：」に数を入れて、「変更を保存」を押します。

- Chat Note は、ノートの目印として、ノートに札を1つ自動で付けます。そのため、ノートに付けられる札は、ここで決めた数より1つ少なくなります。
- 初めの設定では、札の英字は小文字にそろえられます（例：「WEB向け」は「web向け」になります）。
- 場所ごとに数を決めていない場所は、全体の決まりの数になります（初めは5つ）。全体の決まりは、「設定」›「タグ」の「スレッドごとの最大タグ数」です。これから作られるケースの場所も、全体の決まりの数になります。

## スレッドを別の場所へ移す

ケース番号を付け替えたときなどに、スレッドとノートを別の場所へ移せます。**移す元と移す先の両方の場所で、「モデレーション」の権限が要ります。**

1. 管理画面の「管理」›「カテゴリ」で、移す元の場所の「カテゴリを編集」を開きます。ブラウザーのアドレス欄の最後の数字が、その場所の番号です。
2. Chat Note の住所の後ろに `/forum/category/<場所の番号>` を付けて開きます（例：`https://（Chat Note の住所）/forum/category/123`）。
3. 場所の中をすべて移すときは、「スレッドツール」を開き、「すべてを移動」を押します。移るのは、その場所の中のスレッドとノートです（下に並ぶ別の場所の中身は移りません）。
4. 一部だけ移すときは、移すスレッドの横に出る四角い印（□）を押して選び、「スレッドツール」の「スレッドを移動」を押します。
5. 移す先の場所を選んで、「移動」を押します。

## 気を付けること

- 部署とケースの場所の使える人は、基盤の役割とケースの担当者から決まります。基盤の写し（1日1回）とサインインのときに、権限が付け直されます。管理画面で足した人やグループは残りますが、外した部署のグループは元に戻ります。使える人を変えたいときは、基盤の役割や担当者を変えてください。
- 権限の画面の「すべてのカテゴリにコピー」と「このグループの権限をすべてのカテゴリにコピーしてください」は、部署とケースの場所を含む、すべての場所の使える人をまとめて変えます。見られないはずの人に見えるようになることがあるので、使わないでください。
- 「カテゴリを完全削除」を押すと、その場所のスレッドとノートが、すべて消えて戻せません。
