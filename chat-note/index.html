はじめに

Chat Note の概要

Claudia Partner Chat Note（以下、Chat Note）は、社内の会話と記録を、部署やケースごとのカテゴリに残すサービスです。ケースとは、案件・工事・依頼など、会社が番号で管理する仕事の単位です。Claudia Partner の基盤（社員・役割・ケースを管理するしくみ）と同じアカウントでサインインして使います。

主な機能

機能内容
スレッドテーマごとの会話です。返信・引用・編集ができます
チャット1対1、または複数人のチャットです
ノート見出し・表・箇条書きを使って記録を作成します。コメントを付けられます
添付画像・動画・PDF・Office ファイルを添付できます（1ファイルあたり50 MBまで）
返信通知自分の投稿に返信や引用があると通知します
検索閲覧できるカテゴリのスレッドとノートを検索します

構成

項目内容
サインインClaudia Partner のサインインIDでサインインします。2要素認証も基盤と同じです
利用する端末PC では、社員用アプリなどの画面に Chat Note を埋め込んで使えます。スマートフォンとタブレットでは、ブラウザーで Chat Note の URL を開いて使います
閲覧権限基盤の役割とケースの担当者をもとに、自動で設定されます。詳しくはカテゴリと閲覧権限を参照してください
管理画面カテゴリの作成、権限の設定、カテゴリ名の変更、タグの数の変更、スレッドの移動ができます。詳しくは管理画面での設定を参照してください
アプリとの連携アプリの画面への埋め込みと、アプリのサーバーから使う API があります。詳しくはアプリの画面への埋め込みとサーバー用 APIを参照してください

対象外の機能

  • Chat Note には AI の機能はありません。Chat Note が会話の内容を外部の AI サービスに送ることもありません。
  • アプリで AI（要約・下書きなど）を使うかどうか、どの AI サービスを使うかは、アプリを利用する会社で決めます。費用もアプリを利用する会社の負担です。
  • Claudia Partner は、お客様の AI サービスの API キーをお預かりしません。
  • Claudia Partner が提供する別の AI の機能をご希望の場合は、Claudia Partnerサポートにご相談ください。
  • 音声通話とビデオ通話はありません。
  • カレンダーはありません。予定とタスクは基盤の予定・タスクの表で管理し、アプリの画面に表示します。

次に読む

  • 使い方サインイン、スレッド・チャット・ノート、ファイルの添付、返信通知。
  • カテゴリと閲覧権限部署とケースのカテゴリと、閲覧権限が自動で設定されるしくみ。
  • アプリの画面への埋め込みアプリの画面に Chat Note を埋め込む方法と、サインインの流れ。
