Claudia Partner Chat Note（以下、Chat Note）は、社内の会話と記録を、部署やケース（案件・工事・依頼など、会社が番号で管理する仕事の単位）ごとの「場所」（会話と記録をまとめておく所）に残すためのサービスです。Claudia Partner の基盤（社員・役割・ケースなどの情報を管理するしくみ）と同じサインインで使えます。

できること

機能内容
スレッドテーマを決めて会話を残します。返信・引用・編集ができます
チャット1対1、または複数の人で会話します
ノート見出し・表・箇条書きの書式で、共有する記録を作ります。ノートにはコメントが付けられます
添付画像・動画・PDF・Office の文書を、1ファイル50 MBまで添付できます
返信通知自分の投稿に、だれかが「返信」や「引用」で答えると、通知で知らせます
検索自分が見られる場所の中を、言葉で探せます

しくみ

項目内容
サインインClaudia Partner のサインインIDで入ります。2要素の確認（パスワードのほかに、もう1つの方法で本人を確かめること）も、基盤と同じです
使う端末PC では、アプリ（社員用アプリなど）の画面の中に Chat Note を表示して（はめ込んで）使えます。スマホやタブレットからは、Chat Note を直接開いて使えます
見られる場所基盤の役割と、ケースの担当から、自動で決まります。Chat Note の中で、人を手で足す必要はありません。詳しくは場所と、使える人
アプリとの連携画面へのはめ込みと、アプリのサーバーから使う API（アプリから Chat Note を使うための窓口）があります。詳しくはアプリの画面にはめ込むとサーバーから使う API

入っていないもの

  • Chat Note には AI の機能はありません。 会話の中身を、外の AI サービスに送ることもありません。
  • アプリの側で AI（要約・下書きなど）を使うかどうかと、どの AI に送るかは、アプリを使う会社で決めます。その費用も、アプリを使う会社の負担です。
  • Claudia Partner は、お客様が AI を使うための鍵（API キー）をお預かりしません。
  • Claudia Partner が AI の機能を用意する形をご希望の場合は、Claudia Partnerサポートにご相談ください。
  • 通話（音声・ビデオ）はありません。文字と添付で、会話と記録を残すためのサービスです。
  • カレンダーはありません。予定やタスクは、基盤の予定・タスクの表で管理し、アプリの画面で表示します。

受け持ち

もの受け持ち
Chat Note の提供・運用・更新・バックアップClaudia Partner
Chat Note の全体の管理（設定や、場所の構成の調整）Claudia Partner
役割と担当の登録（見られる場所の元になるもの）基盤を使う会社の管理者
Chat Note をはめ込むアプリ（画面とサーバー）アプリを作る側

バックアップは毎日、暗号化して保管しています。

次に読む

  • 使い方サインイン、スレッド・チャット・ノート、添付、返信通知。
  • 場所と、使える人部署とケースの場所が、基盤の役割と担当から決まるしくみ。
  • アプリの画面にはめ込むアプリの画面に Chat Note を表示する方法と、サインインの流れ。
