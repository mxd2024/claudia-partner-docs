管理画面での設定

  4. カテゴリ名を変更する

  7. 注意事項

Chat Note の管理画面では、次の設定ができます。

  • カテゴリの作成
  • カテゴリの権限の設定
  • カテゴリ名の変更
  • スレッド・ノート1件に付けられるタグの数の変更
  • スレッドの移動

部署とケースのカテゴリは、基盤の役割とケースの担当者をもとに自動で作成されます。詳しくはカテゴリと閲覧権限を参照してください。

管理画面を開く

Chat Note の URL の末尾に /forum/admin を付けて開きます。

例：https://chatnote.example.invalid/forum/admin

管理画面を利用するには、事前に手続きが必要です。Claudia Partnerサポートにお問い合わせください（トラブルシューティングとお問い合わせ）。

※ 管理画面では、ノートもスレッドとして表示されます。

カテゴリを作成する

取引先ごとのカテゴリや、役員だけで使うカテゴリなどを作成します。

  1. 「管理」>「カテゴリ」を開き、「カテゴリを追加」>「ローカルカテゴリを追加」をクリックします。
  2. 「カテゴリ名」を入力します。
  3. 「(任意)親カテゴリ」で、上位のカテゴリを選択します。最上位に置く場合は「(なし)」を選択します。
  4. 「(任意) 設定を複製するカテゴリ」で、部署のカテゴリを1つ選択します。選択したカテゴリと同じ権限で作成されます。
  5. 作成したら、続けて「権限を設定する」の手順で権限を設定します。

※ 手順3で何も選択しないと、手順4で選択したカテゴリと同じ親カテゴリの下に作成されます。最上位に置く場合は「(なし)」を選択してください。

注意：手順4で何も選択しないと、サインインした全員（社外の人を含む）が閲覧できる状態で作成されます。作成後すぐに「権限を設定する」の手順で、閲覧させないユーザー・グループの行のチェックをすべて外してください。

権限を設定する

  1. 「管理」>「権限」を開き、「権限を設定」で対象のカテゴリを選択します。
  2. ユーザーを追加する場合は、「ユーザー」欄の「ユーザーを追加」で選択します。グループを追加する場合は、「グループ」欄の「グループを追加」で選択します。
  3. 追加した行で、次の権限にチェックを入れます。
許可する操作チェックを入れる権限
閲覧「カテゴリを検索」「カテゴリにアクセス」「スレッドにアクセス」
投稿（ノートの作成を含む）閲覧の権限に加えて「スレッドを作成」「スレッドに返信」「スレッドにタグ付け」
投稿の整理・スレッドの移動投稿の権限に加えて「モデレーション」
  1. 閲覧させないユーザーとグループの行は、チェックをすべて外します。「登録済みユーザー」の行に残ったチェックは、サインインした全員に適用されます。
  2. 「変更を保存」をクリックします。

※ ユーザーは、一度 Chat Note にサインインすると選択できるようになります。 ※ 社員全員を追加する場合は、グループ「chatnote-employees」を選択します。社外の人はこのグループに含まれません。 ※ 部署のグループ名は、部署のカテゴリを作成したときの名前です（例：営業）。カテゴリ名を変更しても、グループ名は変わりません。 ※ 取引を終えた社外の人は、その人の行のチェックを外して保存します。その人が属するグループの行にチェックがある場合は、引き続き閲覧できます。

カテゴリ名を変更する

  1. 「管理」>「カテゴリ」で、対象のカテゴリの「カテゴリを編集」を開きます。
  2. 「カテゴリ名」を変更し、「変更を保存」をクリックします。

※ 部署のカテゴリ名を変更しても、基盤からの取り込みで元に戻ることはありません。 ※ ケースのカテゴリ名は「ケース番号 件名」で、基盤の件名に合わせて更新されます。管理画面で変更しても、次回の取り込み（1日1回）のあと、またはそのカテゴリを次に開いたときに、基盤の件名に戻ります。

タグの数の上限を変更する

カテゴリごとに、スレッド・ノート1件に付けられるタグの数の上限を設定できます。

  1. 「管理」>「カテゴリ」で、対象のカテゴリの「カテゴリを編集」を開きます。
  2. 「Tags per topic」の「最大：」に数を入力し、「変更を保存」をクリックします。

※ ノートには、Chat Note が目印のタグを1つ自動で付けます。そのため、ノートに追加できるタグは「最大：」の数より1つ少なくなります。 ※ 初期設定では、タグの英字は小文字になります（例：「WEB向け」は「web向け」）。 ※ 上限を設定していないカテゴリには、全体の設定が適用されます（初期値は5）。全体の設定は「設定」>「タグ」の「スレッドごとの最大タグ数」です。今後作成されるケースのカテゴリにも、全体の設定が適用されます。

スレッドを別のカテゴリへ移動する

ケース番号を変更したときなどに、スレッドとノートを別のカテゴリへ移動できます。移動元と移動先の両方のカテゴリで「モデレーション」の権限が必要です。

  1. 「管理」>「カテゴリ」で、移動元のカテゴリの「カテゴリを編集」を開き、ブラウザーのアドレス欄の最後にある数字を確認します。この数字がカテゴリの番号です。
  2. Chat Note の URL の末尾に /forum/category/<カテゴリの番号> を付けて開きます（例：https://chatnote.example.invalid/forum/category/123）。
  3. すべてを移動する場合は、「スレッドツール」>「すべてを移動」をクリックします。下位のカテゴリの内容は移動しません。
  4. 一部を移動する場合は、スレッドの横のチェックボックス（□）で選択し、「スレッドツール」>「スレッドを移動」をクリックします。
  5. 移動先のカテゴリを選択し、「移動」をクリックします。

注意事項

  • 部署とケースのカテゴリの権限は、基盤からの取り込み（1日1回）とサインインのときに、基盤の役割とケースの担当者をもとに設定し直されます。管理画面で追加したユーザーやグループは残りますが、外した部署のグループには、権限が再び付与されます。権限を変える場合は、基盤の役割やケースの担当者を変更してください。
  • 「権限」画面の「すべてのカテゴリにコピー」と「このグループの権限をすべてのカテゴリにコピーしてください」は使用しないでください。表示中の権限が、部署とケースを含むすべてのカテゴリにコピーされます。
  • 「カテゴリを完全削除」を実行すると、そのカテゴリのスレッドとノートはすべて削除され、元に戻せません。
