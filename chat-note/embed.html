アプリと連携する

アプリの画面にはめ込む

このページの内容

  1. 使う URL
  2. はめ込みを許す相手
  3. サインインの流れ
  4. スマホから使うとき

アプリ（社員用アプリなど）の画面に、Chat Note を iframe で表示できます。このページの URL は説明用の例です。実際の Chat Note の URL は、利用を始めるときにお知らせします。

使う URL

開きたいものURL
ケースの場所https://chatnote.example.invalid/case/<ケース番号>?logo=off
Chat Note 全体https://chatnote.example.invalid/?logo=off
  • ?logo=off を付けると、左上のロゴとサービス名を表示しません。はめ込むとき向けです。
  • <ケース番号> は、Claudia Partner の基盤のケース番号です。半角の英数字とハイフンで2〜31文字、先頭は英数字にしてください。
  • ケースの担当者でない人が開くと、その場所に参加していないという知らせが表示されます。
  • Chat Note にないケース（基盤にない番号、担当者のいないケース）を開くと、まだ Chat Note にないという知らせが表示されます。
html<iframe src="https://chatnote.example.invalid/case/A-1001?logo=off"
        style="width:100%;height:100%;border:0" title="Chat Note"></iframe>

はめ込みを許す相手

Chat Note は、許可した住所（URL）の画面の中にだけ表示されます。アプリの URL を、Claudia Partnerサポートにお知らせください。登録が済むまでは、アプリの画面にはめ込んでも表示されません。

  • 許可する単位は「https:// ＋ ホスト名（＋ポート）」です。
  • アプリは、Chat Note と同じサイト（同じ登録ドメインの https）に置いてください。別のドメインに置くと、ブラウザーが、枠の中のサインインした状態を保てないことがあります（とくに Safari）。

サインインの流れ

Claudia Partner のサインインの画面は、はめ込んだ枠の中には表示されません。そのため、次の流れになります。

  1. 枠の中の Chat Note で、社員が「Claudia Partner でサインイン」を押します。
  2. 小さな窓（ポップアップ）が開き、そこでサインインします。
  3. 終わると小さな窓は閉じ、枠の中の Chat Note が開き直します。

アプリの側で、特別な処理は要りません。ただし、ブラウザーの設定で、アプリの URL からのポップアップを止めていないことが必要です。

スマホから使うとき

スマホやタブレットでは、アプリにはめ込まず、ブラウザーで Chat Note の URL を直接開いて使えます。アプリから Chat Note へリンクするときは、?logo=off を付けずに開いてください。
