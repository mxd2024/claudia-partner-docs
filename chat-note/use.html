サインインする

  1. 会社から知らされた Chat Note の住所（URL）を開きます。ほかのアプリの画面の中に Chat Note がある（はめ込まれている）場合は、そのアプリの画面を開きます。
  2. 「Claudia Partner でサインイン」を押します。
  3. Claudia Partner のサインインIDとパスワードを入れます。続けて、パスワードとは別の方法で、もう一度本人確認をします（2要素の確認）。
  • はめ込まれた画面では、サインインのために小さな窓（ポップアップ）が開きます。サインインが終わると窓は閉じ、Chat Note が表示されます。
  • ブラウザー（ホームページを見るためのソフト）がポップアップを止める設定の場合は、そのアプリの住所からのポップアップを許可してください。
  • 終えるときは、画面の右上の「ログアウト」を押します。ログアウトで終わるのは Chat Note だけです。共用の PC では、ログアウトのあと、ブラウザーもすべて閉じてください。
  • Claudia Partner にメールアドレスが登録されていない人は、Chat Note を使えません。会社の管理者に、メールアドレスの登録を頼んでください。

画面の見方

場所内容
左の列「スレッド」（テーマごとの会話）、「チャット」（相手を決めた会話）、「ノート」（書式付きの記録）の切り替えと、場所（カテゴリ）の一覧
中の列選んだ場所の、スレッド・チャット・ノートの一覧。「一覧を絞り込む」に言葉を入れると、いま表示しているページの中で、名前にその言葉を含むものだけを表示します。本文から探すときは、右上の「検索」を使います
右の広い枠開いた会話やノートの中身と、書く欄
右上返信通知、検索、通知音のオン・オフ、ログアウト

スマホでは、画面の幅に合わせて並びが変わります。一覧は画面の上に横一列で並び、その下に中身が表示されます。

スレッドで会話する

  1. 左の列で「スレッド」を選び、場所を選びます。
  2. 「＋」を押し、タイトルと最初のメッセージを書いて作ります。
  3. 一覧からスレッドを開き、下の欄に書いて送ります。
  • 書く欄で Enter キーを押すと、改行になります。送るときは、Ctrl キーを押しながら Enter キーを押します（Mac は ⌘ キーを押しながら Enter キー）。
  • 投稿ごとに「返信」「引用」「編集」「削除」ができます。編集と削除ができるのは、ふつうは自分の投稿だけです。場所の管理役（会社が決めた、その場所の投稿を整理する人）は、ほかの人の投稿も整理できます。
  • 古い投稿は、「以前のメッセージを表示」を押すと読めます。

チャットで話す

  1. 左の列で「チャット」を選び、「＋」を押します。
  2. 相手の名前を入れて探し、出てきた人を選びます。何人でも選べます。
  3. 1人を選ぶと1対1、2人以上を選ぶとグループのチャットになります。

社員は、Chat Note を使っている全員から選べます。社外の協力会社の人（パートナー）は、同じ部署やケースの場所を使っている人だけを選べます。

ノートを作る

ノートは、指示書や議事録など、見出しや表を使って整えて残したい記録に使います。

  1. 左の列で「ノート」を選び、場所を選びます。
  2. 「＋」を押し、タイトルと本文を書いて保存します。
書式使い方
見出し・太字・箇条書き・表書く欄の上のボタンで入れます
2列の表にする書く欄で、「項目」と「値」が1行ずつ交互に並んだ部分を選び、「選択した行を2列に」を押すと、2列の表になります
コメント開いたノートの下の欄から書きます

ファイルを添付する

「＋ 添付」を押すか、書く欄にファイルをドラッグ（マウスで押さえたまま運んで離す）します。画像は貼り付けもできます。

項目内容
大きさ1ファイル50 MBまで。画像は、縦か横が5,000ピクセルを超えると添付できません。大きな画像は、表示用に縮めて表示します
形式画像（jpg・png・webp・gif）、動画（mp4）、PDF、Word・Excel・PowerPoint（doc・docx・xls・xlsx・ppt・pptx）

返信通知と未読

  • スレッドやノートで、自分の投稿にだれかが「返信」か「引用」で答えると、右上の鈴の印に数が出ます。押すと一覧が開き、「すべて既読にする」で消せます。
  • 投稿を選ばずに書き足されたものや、チャットの会話は、鈴の印には出ません。チャットは、一覧の未読の印で確かめます。
  • 「通知音」で、通知の音のオン・オフを切り替えられます。
  • 一覧では、新しく更新されたものが上に並びます。

次に読む

  • 場所と、使える人部署とケースの場所が、基盤の役割と担当から決まるしくみ。
