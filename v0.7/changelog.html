2026-10-08 / 文書改訂12 / 配布物・説明の整合修正

  • MCP 1.0.1のライセンス実パスと、資格名の文字種・HTTPS接続での長さの説明を訂正。
  • 管理サイトのDropbox接続のコードと、公開APIの操作で返るコードを区別。Dropboxの同意、フォルダーごとの読取許可、解除と再接続を補足。
  • 連絡先・用語・例の名称を確認し、残る個別環境の表現を一般化。開発用loopbackのCookieとメモリセッションの条件を補足。

固定API契約、134操作、MCP 8ツール、入力・応答の型は同じです。基盤・認証・資格の設定変更はありません。

2026-10-08 / 文書改訂11 / API 0.7.0-experimental

元のデザインと構成を維持して、文言と仕様を更新しました。

  • 2026-10-07の固定OpenAPIに合わせ、134操作を掲載。serviceのmetadataとimportを追加。既存操作のパスと操作IDは保持。
  • MCPクライアント1.0.1の配布物、CA、分割送信、キーの期限と上限、準備中の状態を反映。公開読取確認と未確認の書込・環境を区別。
  • Dropboxの管理サイトでの限定した確認と、アプリ向け選択API・共有URLの状態を区別。
  • 個別顧客の支援・担当範囲・配置先・受付条件を共通要件から除外。サンプルアプリを追加し、v2のケースとv1のジョブを区別。
  • 稼働版と文書対象版を区別し、公開Issuesに資格や顧客情報を投稿しない案内へ変更。

2026-10-04 / 初回公開 / API 0.7.0-experimental

Claudia PartnerのAPI・MCP共通ドキュメントを公開しました。

  • 公開API132操作の機械仕様（OpenAPI）と、操作ごとの認可・再送・エラーの説明。
  • 認証の入手から最初のリクエストまでの手順（利用者のログイン、service接続）と、環境別のOpenAPIの作り方。
  • 共通ルール、表・行の操作、通しの手順、アプリの推奨構成、版と対応状況の説明。
  • 取込用MCP 8ツールの導入手順、接続できないときの対処、認可の範囲。
  • 接続情報の確認項目。

互換性と廃止

experimental契約は変更され得ます。利用版を固定して更新前に差分確認してください。既存v1を自動的にv2へ移行しません。破壊的な仕様変更は別版の資料と移行条件で案内し、既存の版別資料を保持します。正式なサポート期間・廃止予告期間は未確定です。未確定の期間を保証として扱わないでください。
