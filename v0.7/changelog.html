2026-10-29 / ドキュメント改訂26 / API 0.7.0-experimental

  • 利用者として接続するの「ログインの直後とセッションの期限」に、端末コードの方式（OAuth 2.0 Device Authorization Grant）で認証し直すときは、シークレットウィンドウ（プライベートウィンドウ）で認証のURLを開いてもらうことを追加。API契約の変更はありません。

2026-10-28 / ドキュメント改訂25 / API 0.7.0-experimental

  • MCPの導入の、配布物の入手、キーの発行と保存、利用の終了を、管理サイトの「MCP接続管理」の画面に合わせた。「接続する端末・用途」の入れ方と、接続キーを取り消したときの影響を追加。
  • MCPの対応範囲とトラブル対応の401の対処と、用語集の「管理サイト」を、同じ画面に合わせた。
  • 機械仕様（OpenAPI）とMCPクライアント1.0.1の内容は、変わりません。

2026-10-28 / ドキュメント改訂24 / API 0.7.0-experimental

  • 表とデータの更新に、IDの決まりと使えない名前、列ごとの役割の上限、役割と行の範囲（read_scope・write_scope）、行がある表の定義の変え方、アプリと共有の表の決まりを追加。関連・所属・transaction・eventsが試験提供の機能であることと、eventsが取りに行く形であることを明確にした。
  • serviceとして接続するに、申請の本文の例、期限の延ばし方、定時の集計・同期、使い始める前の確認、断られるときの答えを追加。
  • 画像とDropbox連携とMCPの対応範囲とトラブル対応から、日付つきの確認の経緯を外した。画像とDropbox連携に、サムネイルと今の原本の関係と、同時に処理する数・待ち時間を追加。
  • 機械仕様（OpenAPI）は、2026-10-07の固定契約のままです。

2026-10-28 / ドキュメント改訂23 / API 0.7.0-experimental

  • 用語集の「基盤」と「基盤API」の説明を、ほかのページと同じ言葉にそろえた。意味は変わりません。API契約の変更はありません。

2026-10-28 / ドキュメント改訂22 / API 0.7.0-experimental

  • 改訂21で追加した説明の言葉を直した。表とデータの更新の503のときの対応で、同じキーの再送と、操作の数を減らして送り直すときのキーの関係を明確にした。アプリの登録と運用の削除の範囲の設定で、本文とヘッダーを分けて書いた。API契約の変更はありません。

2026-10-28 / ドキュメント改訂21 / API 0.7.0-experimental

  • 表とデータの更新に、textの値にU+0000（NUL）を含められないこと、ownの範囲で、ほかの人が取り込んだ行が見えないこと、行の削除に必要な列の権限、取り込みの上限と権限、行の多い表でbatchが503になるときの対応を追加。
  • アプリの登録と運用に、削除の範囲を確かめ・設定する操作を追加。
  • 共通ルールに、cursorが使えなくなる条件を追加。
  • 利用者として接続するに、ログインし直すときに、認証し直しが必要なことを追加。
  • 機械仕様（OpenAPI）は、2026-10-07の固定契約のままです。

2026-10-14 / ドキュメント改訂19 / API 0.7.0-experimental

表とデータの更新の「上限」で、見られる範囲の上限を「25,000行・32MiBのどちらかを超えると」に訂正。API契約の変更はありません。

2026-10-14 / ドキュメント改訂18 / API 0.7.0-experimental

  • 新しいセッションの方式の稼働版（2026-10以降）に合わせて、ログイン直後の反映待ちの説明を改めた。無操作の時間・延長・12時間での再ログインと、401のcodeごとの対応を追加。それより前の稼働版での反映待ちの案内は残した。対応状況とバージョンに、方式の行を追加。
  • v2の表の定義（列の型と値、必須と保存の状態、締め、自動で計算する列、列の権限とownerの意味）、ケースと番号（取り込み、case_refの値）、関連と所属、上限、変更の確認と記録を、表とデータの更新に追加。
  • 機械仕様（OpenAPI）は、2026-10-07の固定契約のままです。

2026-10-04 / 初回公開 / API 0.7.0-experimental

Claudia PartnerのAPI・MCP共通ドキュメントを公開しました。

  • 公開API132操作の機械仕様（OpenAPI）と、操作ごとの認可・再送・エラーの説明。

互換性と廃止

experimental契約は変更され得ます。利用版を固定して更新前に差分確認してください。既存v1を自動的にv2へ移行しません。破壊的な仕様変更は別版の資料と移行条件で案内し、既存の版別資料を保持します。正式なサポート期間・廃止予告期間は未確定です。未確定の期間を保証として扱わないでください。
