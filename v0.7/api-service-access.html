GET/v2/access/grants/{subjectId}/{collection}サービス・権限 · service.grantGet

OpenAPI定義ありこの操作へのリンク

本人の表利用権を取得

本人の表利用権を取得。登録された人のaccess tokenと現在権限を検査する。操作固有のMFA・管理権・データ権が追加で必要。 管理操作は登録済みMFA本人、機械操作は専用audienceのservice資格を使う。人のJWTを機械経路へ流用しない。changeはversion必須で、rotateのみjwkが必要。

認証

Bearer JWT。主体と現在権限を確認します。

操作別の認可条件

json{
  "actor_types": [
    "human"
  ],
  "authentication": "current_identity",
  "mfa": true,
  "mfa_when_lifecycle_enabled": true,
  "required_capabilities": [],
  "max_authentication_age_seconds": null,
  "external_human_mfa": true,
  "identity_freshness": {
    "checked_age_seconds": 5,
    "reconciled_age_seconds": 60
  },
  "administrative_session_when_lifecycle_enabled": true,
  "resource_checks": [
    {
      "kind": "management",
      "all_of": [
        "service_administrator",
        "manage_access"
      ],
      "action": "grantGet"
    }
  ]
}

再送と結果確認

json{
  "effect": "read_or_plan",
  "mode": "none",
  "safe_to_repeat": true,
  "result_check": "同じ条件で取得可能。ただし一覧・計画・cursor・fingerprintは現在状態で変化する。計画を再取得しても適用は行わない。"
}

サービス資格の承認・登録・更新・停止・再開・失効。登録された人のaccess tokenと現在権限を検査する。操作固有のMFA・管理権・データ権が追加で必要。 管理操作は登録済みMFA本人、機械操作は専用audienceのservice資格を使う。人のJWTを機械経路へ流用しない。changeはversion必須で、rotateのみjwkが必要。

認証

Bearer JWT。主体と現在権限を確認します。

json{
  "actor_types": [
    "human"
  ],
  "authentication": "current_identity",
  "mfa": true,

  "required_capabilities": [],
  "max_authentication_age_seconds": null,
  "external_human_mfa": true,
  "identity_freshness": {
    "checked_age_seconds": 5,
    "reconciled_age_seconds": 60
  },
  "administrative_session_when_lifecycle_enabled": true,
  "resource_checks": [
    {
      "kind": "management",
      "all_of": [
        "service_administrator"
      ],
      "action": "change"
    },
    {
      "kind": "service_client_authority",
      "any_of": [
        "managed_client_and_manage_access",
        "legacy_client_and_legacy_administrator_scope"
      ]
