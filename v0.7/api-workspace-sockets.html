GET/v2/tables/{collection}/access関連・所属 · workspace.socket.policy.get

OpenAPI定義ありこの操作へのリンク

表の関連・所属方式を取得

表の関連・所属方式を取得。登録された人のaccess tokenと現在権限を検査する。操作固有のMFA・管理権・データ権が追加で必要。 v2はv1と別契約。行所有権・列・所属・現在版を検査する。関連表の一括取引は最大8表・計100行操作で原子的に適用し、親行は既存IDを指定する。

認証

Bearer JWT。主体と現在権限を確認します。

操作別の認可条件

json{
  "actor_types": [
    "human"
  ],
  "authentication": "current_identity",
  "mfa": false,
  "mfa_when_lifecycle_enabled": true,
  "required_capabilities": [],
  "max_authentication_age_seconds": null,
  "external_human_mfa": true,
  "identity_freshness": {
    "checked_age_seconds": 5,
    "reconciled_age_seconds": 60
  },
  "administrative_session_when_lifecycle_enabled": true,
  "resource_checks": [
    {
      "kind": "v2_table_grant",
      "action": "socket.policy.get",
      "checks": [
        "current_role",
        "expiry",
        "row_scope",
        "field_permissions",
        "membership",
        "closed_row_policy"
      ]
    }
  ]
}

再送と結果確認

json{
  "effect": "read_or_plan",
  "mode": "none",
  "safe_to_repeat": true,
  "result_check": "同じ条件で取得可能。ただし一覧・計画・cursor・fingerprintは現在状態で変化する。計画を再取得しても適用は行わない。"
}
