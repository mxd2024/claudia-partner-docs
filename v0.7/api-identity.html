POST/v2/session/logoutセッション · identity.logoutSelf

OpenAPI定義ありこの操作へのリンク

本人セッションを失効

本人セッションを失効。登録された人のaccess tokenと現在権限を検査する。操作固有のMFA・管理権・データ権が追加で必要。 本人と現在セッションの境界を維持する。

認証

Bearer JWT。主体と現在権限を確認します。

操作別の認可条件

json{
  "actor_types": [
    "human"
  ],
  "authentication": "logout_session_binding",
  "mfa": false,
  "required_capabilities": [],
  "max_authentication_age_seconds": null,
  "resource_checks": [
    {
      "kind": "self_session",
      "checks": [
        "issuer",
        "subject",
        "client_id",
        "sid",
        "attempt_id"
      ]
    }
  ],
  "note": "失効済みセッションも同じattempt_idの受領確認に使用できる専用経路。通常APIの有効セッション条件とは別。"
}

再送と結果確認

json{
  "effect": "write",
  "mode": "attempt_id",
  "identifier": "body.attempt_id",
  "safe_to_repeat": true,
  "result_check": "同じセッションとattempt_idで再送し失効受領を確認する。別attempt_idを自動発行しない。"
}
