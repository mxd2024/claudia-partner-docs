POST/v2/app-adoptions/applyアプリ定義・移行 · app-packages.adoptionApply

OpenAPI定義ありこの操作へのリンク

確認済みの既存アプリ台帳を採用

確認済みの既存アプリ台帳を採用。登録された人のaccess tokenと現在権限を検査する。操作固有のMFA・管理権・データ権が追加で必要。 アプリとCSV契約・接続要件・移行の操作。計画を確認してからfingerprintを変えず適用する。空のcsvは対象アプリの取込形式を明示的に無効化する。

認証

Bearer JWT。主体と現在権限を確認します。
