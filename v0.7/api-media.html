画像・添付

← 全操作を検索 · 共通データ型

文書対象版の契約です。実機疎通は未確認。環境での有効化・現在の権限が必要です。

GET/v1/assets/workspaces/{collection}/{rowId}/{field}画像・添付 · media.1.list

OpenAPI定義ありこの操作へのリンク

行の画像・添付（互換パス）の一覧取得

行の画像・添付（互換パス）の一覧取得。登録された人のaccess tokenと現在権限を検査する。操作固有のMFA・管理権・データ権が追加で必要。 v2行のasset_ref列へ関連付ける。親行・列・所属・原本保持方針を検査し、任意URLを受け付けない。

認証

Bearer JWT。主体と現在権限を確認します。

json{
  "actor_types": [
    "human"

  "max_authentication_age_seconds": null,
  "external_human_mfa": true,
  "identity_freshness": {
    "checked_age_seconds": 5,
    "reconciled_age_seconds": 60
  },
  "administrative_session_when_lifecycle_enabled": false,
  "resource_checks": [
    {
      "kind": "v2_media_slot",
      "action": "list",
      "checks": [
        "parent_row",
        "asset_ref_field",
        "membership",
        "field_read_write",
        "current_parent_version",
        "storage_policy"

    }
  ]
}
