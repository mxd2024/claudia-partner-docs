GET/v2/app-policyアプリ管理 · apps.policy

OpenAPI定義ありこの操作へのリンク

アプリごみ箱の保持期間を確認

アプリごみ箱の保持期間を確認。登録された人のaccess tokenと現在権限を検査する。操作固有のMFA・管理権・データ権が追加で必要。 アプリ台帳の計画・適用・状態遷移。画面プログラムの環境を自動実行する契約ではない。

認証

Bearer JWT。主体と現在権限を確認します。

操作別の認可条件

json{
  "actor_types": [
    "human"
  ],
  "authentication": "current_identity",
  "mfa": true,
  "mfa_when_lifecycle_enabled": true,
  "required_capabilities": [],
  "max_authentication_age_seconds": null,
  "external_human_mfa": true,
  "identity_freshness": {
    "checked_age_seconds": 5,
    "reconciled_age_seconds": 60
  },
  "administrative_session_when_lifecycle_enabled": true,
  "resource_checks": [
    {
      "kind": "management",
      "all_of": [
        "service_administrator",
        "manage_access"
      ],
      "action": "policy"
    }
  ]
}

再送と結果確認

json{
  "effect": "read_or_plan",
  "mode": "none",
  "safe_to_repeat": true,
  "result_check": "同じ条件で取得可能。ただし一覧・計画・cursor・fingerprintは現在状態で変化する。計画を再取得しても適用は行わない。"
}

application/problem+json · Problem

アプリ登録・更新を計画

アプリ登録・更新を計画。登録された人のaccess tokenと現在権限を検査する。操作固有のMFA・管理権・データ権が追加で必要。 アプリ台帳の計画・適用・状態遷移。画面プログラムの環境を自動実行する契約ではない。

認証

Bearer JWT。主体と現在権限を確認します。
