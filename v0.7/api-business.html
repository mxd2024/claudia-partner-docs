GET/v1/ai/sessions/{id}業務・本人情報 · ai_session.get

OpenAPI定義ありこの操作へのリンク

AIセッションを取得

AIセッションを取得。登録された人のaccess tokenと現在権限を検査する。操作固有のMFA・管理権・データ権が追加で必要。 現在権限とMFAでAIセッションを取得する。

認証

Bearer JWT。主体と現在権限を確認します。

操作別の認可条件

json{
  "actor_types": [
    "human"
  ],
  "authentication": "current_identity",
  "mfa": true,
  "mfa_when_lifecycle_enabled": true,
  "required_capabilities": [],
  "max_authentication_age_seconds": null,
  "external_human_mfa": true,
  "identity_freshness": {
    "checked_age_seconds": 5,
    "reconciled_age_seconds": 60
  },
  "administrative_session_when_lifecycle_enabled": false,
  "resource_checks": [
    {
      "kind": "registered_operation_authorization",
      "operation_id": "ai_session.get",
      "checks": [
        "current_roles",
        "resource_scope",
        "field_policy"
      ]
    }
  ]
}

json{
