# 接続情報を依頼する

基盤に接続するための情報は、環境ごとに違います。このサイトから推測せず、環境管理者から受け取ります。このページでは、何を受け取るのか、どう依頼するのかを説明します。

## 受け取る情報

| 項目 | 内容 | 何のための情報か |
| --- | --- | --- |
| 基盤 | HTTPS origin、API版、有効な機能 | 基盤APIを呼ぶ接続先 |
| 認証サービス | issuer（認証サービスのURL）、audience（トークンの宛先）、認証方式、必要なMFA | 利用者のログインと、トークンの取得 |
| 利用者用のクライアント | 登録済みのclient_id（アプリのID）、redirect_uri（ログイン後に戻るURL）、scope（求める権限の種類） | 利用者としての接続 |
| 利用者 | ログインの方法、利用する組織、必要な表の権限 | 利用者としての接続 |
| 管理者の権限 | アプリ定義の登録、利用者の権限の設定、serviceの承認を行う利用者への、管理権限（`manage_access`と`service_administrator`の両方）の付与 | 管理の操作 |
| 検証用の表 | collection（表の識別子）、現在のschema_version、許可する操作、検証用の行 | 最初の読み書き |
| 管理サイト（MCPの取込を使う場合） | 管理サイトのHTTPS origin、利用者のアカウント。契約の環境ごとに、個別に渡されます | MCPアダプターの接続先 |
| 画像（使う場合） | 参照できる保存先（store）の名前と、Dropboxのどのフォルダーに対応するか。Dropboxの接続 | 画像の参照の登録 |
| 証明書 | 公開の認証局、または環境管理者が渡した検証用の証明書 | TLSの検証 |

基盤、あなたのアプリ、認証サービスは、それぞれ別のURLです。このサイトは、仕様を配信するだけで、APIのサーバーではありません。

## 依頼する

接続の申請は、環境管理者が受け付けます。受付の手段は、メールです。

**現在の受付メール：morita@meta-xdesign.com**

一次回答は、**受信した日の翌営業日までを目標**にしています。保証付きのSLAではありません。一次回答は、受付の確認、不足している情報の確認、対応の見込みの連絡です。接続情報を渡したことを意味しません。利用を始められる日は、申請の内容を確認した後に、お知らせします。

### 依頼メールの雛形

```text
件名：【開発接続申請】環境名／利用目的

依頼者・所属：
返信先：
対象環境（不明なら用途を記載）：
利用目的：
利用区分：利用者 / service / MCPの取込（管理サイトのアカウント）
必要な表・操作（閲覧、登録、更新など）：
管理権限が必要な利用者（アプリ定義の登録、権限の設定、serviceの承認）：
画像（Dropbox）の利用：要 / 不要（要の場合、対象のアプリ・表・列、対象のフォルダー、読み取り / 保存の用途、原本の保管の責任）：
利用開始希望日・利用終了日：
検証用データの希望：
登録済みclient_id（ある場合）：
redirect_uri（利用者用のクライアントを新規に登録する場合）：
補足：
```

パスワード、アクセストークン、リフレッシュトークン、秘密鍵、cookieは、メールに書かないでください。接続先、設定、資格の渡し方は、依頼者と、許可する範囲を確認してから案内します。

## 受け取った後に確認すること

- 基盤のURLが、HTTPSになっている。
- 受け取ったclient_idとredirect_uriが、ログインの設定と一致している。
- 検証用の表の名前と、許可される操作が分かっている。

次は、[利用者として接続する](https://mxd2024.github.io/claudia-partner-docs/v0.7/guide/authentication.md)、または[serviceとして接続する](https://mxd2024.github.io/claudia-partner-docs/v0.7/guide/service-access.md)へ進みます。
