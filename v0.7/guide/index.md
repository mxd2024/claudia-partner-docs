# インフラと、お客様専用アプリの全体像

**読み手**: Claudia Partner を導入する、お客様の経営者・担当者・開発者。
**このページで分かること**: Claudia Partner のインフラが、何を提供し、お客様専用アプリと、どう役割を分けているか。
**このページに書かないこと**: 接続の手順と、APIの仕様。それらは、後のページにあります。

## 背景と考え方

Claudia Partner は、セキュアなインフラと、お客様専用アプリ（伴走支援で立ち上げ）で構成されます。インフラとは、ログイン、権限、データなどの、共通のサービスのことです。お客様専用アプリとは、お客様の業務のために作る、専用のアプリのことです。インフラは、お客様の複数のアプリで、共通に使います。

- **共通にする部分と、お客様ごとに作る部分を、分ける**: ログイン、権限、データの保管は、間違えると影響が大きい部分なので、共通のインフラに集めます。業務の画面や手順は、お客様ごとに、専用アプリで作ります。
- **権限は、要求のたびに、判断する**: 誰が、何を使えるかは、利用者が操作するたびに、インフラが判断します。アプリやAIが、自分で権限を広げることは、できません。
- **お客様ごとの、専用の環境で動かす**: インフラは、お客様ごとに分けた専用の環境で動きます。大手企業のセキュリティ水準を見据えて、認証、権限管理、監査、データ保全を設計しています。

## 全体像

インフラは、サービスを使うための入口を、2つ提供します。アプリ向けのAPI（プログラムがサービスを呼び出す入口）と、AI向けのMCP（AIが外部のサービスを使うための、共通の接続方式）です。

```text
利用者 --(画面を使う)--> お客様専用アプリ --(API)--> [ Claudia Partner インフラ ] --(原本を参照)--> Dropbox（お客様のクラウドストレージ）
AIエージェント --(MCP)--> [ Claudia Partner インフラ ]
```

## 構成要素と通信

```text
[お客様の側：お客様専用アプリ（伴走支援＝立ち上げを、提供者が一緒に進める支援）]
  ブラウザ（Mac / Windows） --(1 画面を開く)--> お客様専用アプリの入口（HTTPS・専用URL。社内LANだけなら不要）
    --> アプリサーバー（配置先：クラウド or お客様の社内サーバー。画面の配信・BFF（アプリ用バックエンド）・業務サービス）
  AIエージェント（AIが利用者を助ける）
[Claudia Partner インフラ（提供者：MXD）]
  入口: API（api.claudia-partner.com）／ MCP    ← アプリサーバーは、暗号化された接続経路で API を呼ぶ（2）。AIエージェントは MCP を使う
  SSO・MFAと、要求ごとの認証・認可（3）
  お客様ごとの専用環境（仮想サーバー）の、サービスを提供する中核：
    認証・認可（3） / データ（4：表と行の保管、作成・取得・更新・削除） / アプリ定義の管理（4：登録・更新・停止） / メディア（5：画像・PDFの参照）
  メディアの原本は、お客様のDropboxにあり、インフラが参照する（5）
```

1. **画面を開く**: ブラウザは、専用URLの入口を通って、アプリサーバーから、画面を受け取ります。アプリサーバーは、画面を配信し、業務サービスを動かし、インフラとの間を、BFF（アプリ用のバックエンド）でつなぎます。
2. **インフラの入口を使う**: アプリサーバーは、暗号化された接続経路で、インフラのAPIを呼びます。AIエージェントは、インフラのMCPを使います。
3. **認証・認可**: インフラは、SSO（1回のログインで使える仕組み）とMFA（パスワードに加えて、もう1つの確認）で、利用者を確かめます（認証）。要求のたびに、使ってよい範囲かを判断します（認可）。
4. **データとアプリ定義**: 表と行を保管し、読み書きできるようにします。アプリ定義（お客様専用アプリが使うデータと権限の登録）の、更新と停止も行います。
5. **メディアの参照**: 画像やPDFの原本は、お客様のDropboxに置いたままで、インフラが参照して使います。

## インフラが提供するサービス

- **認証・認可**: 利用者を確かめ（認証）、要求のたびに、使ってよい範囲かを判断します（認可）。
- **データ**: 表と行を保管し、作成・取得・更新・削除ができます。変更の履歴も残ります。
- **メディア**: 画像やPDFなどのファイルを扱います。原本は、お客様のDropboxに置いたまま、参照して使えます。
- **アプリ定義の管理**: お客様専用アプリが使うデータと権限を、アプリ定義として登録します。更新と、停止もできます。

## 役割の分担

- **お客様（画面・業務ロジック・接続資格を管理）**: お客様専用アプリは、別のクラウドサーバー、またはお客様の社内のサーバー（オンプレミス）に配置します。接続のための資格（アクセストークン）の安全な保管と、APIの仕様を守ることを担います。Dropbox上の原本の保全は、お客様が管理します。
- **提供者（MXD）（API・認可・データベース・インフラの運用を管理）**: IDと権限の管理API、監視、バックアップを提供します。
