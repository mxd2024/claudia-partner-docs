# 対応状況とバージョン

文書対象は **API 0.7.0-experimental / 2026-10-07の固定契約 / 文書改訂14** です。experimentalは変更され得る試験提供段階を示します。API契約、文書、MCPクライアント、実配備の版は別に管理します。ブランチの先頭を稼働版とみなしません。

## 文書対象版の範囲

API 134 operations / OpenAPI 134 operations / MCP 8 import tools / MCP adapter 1.0.1

134操作の契約があっても、すべてが接続環境で有効とは限りません。新たに記載したserviceのmetadata・importは、承認された表・列・行・操作に限られ、人のJWTでは呼べません。

## 確認記録の読み方

契約ファイルは固定版とSHA-256で照合済み。MCPの1.0.1 ZIP、CAバンドル、ソースとの一致も確認しました。MCPの公開読取は[Issue 16の報告](https://github.com/mxd2024/claudia-partner-docs/issues/16)に基づき、今回の文書改訂で資格を使って再実行したものではありません。

Dropboxは提供者環境での実機確認記録を読み取り、設計に沿った接続・読取・権限取消・変更・解除・再接続を確認しました。限定された認証条件で、独立した受入ではありません。障害時の復旧、通常のMFA条件、Dropbox側の失効の独立確認は残っています。個別環境名や管理経路は公開しません。

出典の固定版・公開ファイルSHAは[仕様ファイル](specs.md)と[公開来歴JSON](../provenance.json)、改訂の追跡は[Issue 9](https://github.com/mxd2024/claudia-partner-docs/issues/9)を参照してください。
