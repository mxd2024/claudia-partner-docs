# 対応状況とバージョン

このドキュメントは、**0.7.0-experimental**の公開契約を対象にしています。experimentalは、仕様や提供条件が変更されることがある、試験提供の段階です。

## 現在の範囲

API 132 operations / OpenAPI 132 operations / MCP 8 import tools

OpenAPIに載る132操作と、MCPの8ツールは、別の窓口です。どちらも、環境での有効化と、呼び出す側の権限が必要です。

## 機能ごとの状態

| 機能 | 状態 | 補足 |
| --- | --- | --- |
| 基盤API | [環境による] | 132操作。機能ごとに有効化が必要です |
| OpenAPI | [提供中] | 132操作を掲載しています |
| MCP（取込） | [提供中] | 8ツール。経路は、AIエージェント → 手元のMCPアダプター → 管理サイトの取込API です。既知の制約: 入口で拒否される（403、`error code: 1010`）ことがあります。提供者側の修正が必要で、修正版の提供日は未定です。[MCPの対応範囲とトラブル対応](https://mxd2024.github.io/claudia-partner-docs/v0.7/guide/mcp-support.md) |
| MCP（全APIサービス） | [準備中] | 対象です。提供に向けて準備中です |
| 外部の原本の画像参照 | [環境による] | 利用には、環境側の設定と、原本への到達性の確認が必要です |
| 正式なログイン（SSO・MFA）の環境での、画像の利用 | [準備中] | |
| Dropboxのフォルダー選択、共有URLの解決 | [未提供] | |
| macOSでのMCPのキー保存 | [未提供] | |

状態の読み方は、[基盤の考え方と責任分界](https://mxd2024.github.io/claudia-partner-docs/v0.7/guide/principles.md)にあります。ドキュメントに載っていることは、ご利用の環境で使えることを意味しません。接続先の実際の提供状態を、環境管理者に確認してください。

## 版の考え方

APIの版に対応した、`/v0.7/`のURLを使います。ページの中のリンクも、同じ版に留まります。最新版へのリンクだけで、利用している仕様を置き換えないでください。

同じ版の説明の訂正は、このサイトで更新します。APIの互換性が変わるときは、新しい版を追加し、古い版の説明を残します。サイトの入口は、最新の案内を示し、版ごとの入口は、使い続けられます。

更新の内容は、[変更履歴](https://mxd2024.github.io/claudia-partner-docs/v0.7/guide/changelog.md)で確認できます。
