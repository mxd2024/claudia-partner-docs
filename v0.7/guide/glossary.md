# 用語集

このガイドで使う用語の意味です。各ページでも、初めて出る場所で、短く説明しています。

## 登場する人ともの

| 用語 | 意味 |
| --- | --- |
| 利用者（human） | 基盤にログインして、アプリやAIエージェントを使う人。基盤は、操作のたびに、その時点の権限とMFAを確認する |
| あなた（開発者） | このガイドを読み、アプリや処理を作る人 |
| あなたのアプリ | あなたが作る、画面とサーバー側を持つアプリ |
| アプリのサーバー側（BFF） | ブラウザーで使うアプリが、トークンを預かるために持つ、サーバー側の部分 |
| service | 人の操作なしに動く処理（バッチや連携）。管理者の承認を受けた、表・列・操作・期限の範囲だけで動く |
| AIエージェント | 利用者を助けて、操作を行うもの。利用者の権限を超えられない |
| 基盤 | Claudia Partner 基盤。データ、権限、画像を管理し、基盤APIで提供する窓口 |
| 基盤API | 基盤に接続するためのAPI。パスは`/v1`と`/v2`の系列 |
| 認証サービス（IdP） | 利用者のログインを担うサービス。OIDC（OpenID Connect）を使う |
| 組織の管理者 | あなたの組織で、利用者の権限を設定し、アプリ定義を登録し、serviceを承認する人。管理権限（`manage_access`と`service_administrator`の両方）と、MFAが必要。権限の付与は、環境管理者に依頼する |
| 環境管理者 | 提供者側の窓口。接続情報を渡し、機能を有効にする人 |
| `manage_access` | 利用者と、表の権限を設定できる管理権限 |
| `service_administrator` | serviceの申請・承認・停止など、serviceの管理を行える管理権限 |
| 環境 | 基盤の接続先の単位。接続先のURL、有効な機能、利用者が、環境ごとに異なる |
| 管理サイト | Claudia Partnerの管理サイト。「取込・出力」から、MCPの取込を行える |

## ログインと資格

| 用語 | 意味 |
| --- | --- |
| OIDC | ログインの標準の方式（OpenID Connect）。認証サービスが、利用者を確認する |
| PKCE | 認可コードを盗まれても使えないようにする仕組み。ログインの要求ごとに、使い捨ての値を使う |
| MFA | 多要素認証。パスワードに加えて、もう1つの確認を行う |
| アクセストークン | 基盤APIの呼び出しに付ける、有効期限のある資格 |
| リフレッシュトークン | アクセストークンを更新するための資格 |
| issuer | 認証サービスのURL（識別子） |
| client_id | 認証サービスに登録した、アプリを識別するID。環境管理者から受け取る |
| redirect_uri | ログインの後に、認証サービスが利用者を戻すURL。登録済みのものだけが使える |
| scope | トークンに求める、権限の種類 |
| 接続キー | MCPアダプターが管理サイトに接続するための、個人用の資格。利用者のログインやserviceとは別 |
| provision / activate | serviceを使えるようにする手順。provisionで接続の情報を用意し、activateで有効にする |

## データ

| 用語 | 意味 |
| --- | --- |
| 表 / collection | データを入れる表。collectionは、その識別子で、画面のラベルとは別 |
| definition | 表の定義（列と型）。`schema_version`は、その版 |
| version | 行や資格など、取得した対象そのものの版。更新の競合を検出するのに使う |
| revision | アプリの状態や一覧などの、変更の版 |
| plan / fingerprint | 適用の前に作る、変更の差分と確認の対象。適用のときに、同じ計画かを照合する |
| app | 表、依存先、版を登録した、アプリの単位。画面のプログラムの配置とは別 |
| draft / committed | 表の保存の状態。案件の業務の進み具合とは別 |
| custody | 画像の原本の保管の方式。`managed_original`（基盤が管理）と`external_reference`（外部の原本への参照） |
| policy / store | 画像の許可条件（policy）と、参照できる保存先の名前（store）。policyは、APIで取得する |

## 通信と再送

| 用語 | 意味 |
| --- | --- |
| `Idempotency-Key` | 同じ操作の再送を見分けるキー。二重に実行されないようにする |
| `If-Match` | 操作が要求する、期待する版を指定するヘッダー |
| `request_id` | 要求ごとの識別子。問い合わせに添える |
| 結果不明（`OUTCOME_UNKNOWN`） | 操作が完了したか、確認できない状態。失敗とは限らない |

## AIエージェント

| 用語 | 意味 |
| --- | --- |
| MCP | AIエージェントが、ツールを呼び出すための、共通の接続方式 |
| MCPホスト | MCPのツールを呼び出す、AIエージェントのアプリケーション |
| MCPアダプター | 手元のPCで動き、AIエージェントのMCPを、管理サイトへの接続に変換するプログラム |
