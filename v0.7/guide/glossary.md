# 用語集

## 基盤とアプリ

| 用語 | 意味 |
| --- | --- |
| 基盤 | Claudia Partner 基盤。データ、権限、画像を、アプリとAIエージェントに提供する共通の窓口 |
| 基盤API | 基盤に接続するためのAPI。パスは `/v1` と `/v2` の系列 |
| 環境 | 基盤の接続先の単位。接続先のURL、有効な機能、利用者が環境ごとに異なる |
| 環境管理者 | 提供者側の窓口。環境の接続情報の交付と、機能の有効化を行う |
| 管理者（組織） | あなたの組織で、利用者の権限の設定とserviceの承認を行う人。`can_manage_access`とMFAが必要 |
| 認証サービス（IdP） | ログインを担うサービス。OIDC（OpenID Connect）を使う |
| 本人（human） | ログインした人。基盤は、その時点の権限とMFAを確認する |
| service | 管理者の承認を受けた、人の操作を介さない接続。表・列・操作・期限が限定される |
| アプリのサーバー側（BFF） | ブラウザーで使うアプリが、トークンを保持するために持つサーバー側の部分 |
| アクセストークン | 基盤APIへの呼び出しに付ける資格。有効期限がある |
| 管理サイト | Claudia Partnerの管理サイト。「取込・出力」から、MCPの取込を行える |

## データ

| 用語 | 意味 |
| --- | --- |
| collection | 表の識別子。画面に表示するラベルとは別 |
| definition | 表の定義（列と型）。`schema_version` はその版 |
| version | 行や資格など、取得した対象そのものの版。更新の競合の検出に使う |
| revision | アプリの状態や一覧などの変更の版 |
| plan / fingerprint | 適用の前に作る、差分と確認の対象。適用のときに、同じ計画かを照合する |
| app | 表、依存先、版を登録した、アプリの単位。画面のプログラムの配置とは別 |
| draft / committed | 表の保存の状態。案件の業務の進み具合とは別 |
| custody | 画像の原本の保管の方式。`managed_original`（基盤が管理）と `external_reference`（外部の原本への参照） |

## 通信と再送

| 用語 | 意味 |
| --- | --- |
| `Idempotency-Key` | 同じ操作の再送を識別するキー。二重に実行されないようにする |
| `If-Match` | 操作が要求する、期待する版を指定するヘッダー |
| `request_id` | 要求ごとの識別子。問い合わせに添える |
| 結果不明（`OUTCOME_UNKNOWN`） | 操作が完了したか、確認できない状態。失敗とは限らない |

## AIエージェント

| 用語 | 意味 |
| --- | --- |
| MCP | AIエージェントがツールを呼び出すための、共通の接続方式 |
| MCPホスト | MCPのツールを呼び出す、AIエージェントのアプリケーション |
| MCPアダプター | 手元のPCで動き、AIエージェントのMCPを、管理サイトへの接続に変換するプログラム |
| 接続キー | MCPアダプターが管理サイトに接続するための、個人用の資格。本人ログインやserviceとは別 |
| provision / activate | serviceを使えるようにする手順。provisionで接続の情報を用意し、activateで有効にする |
| policy / store | 画像の許可条件（policy）と、参照できる保存先の名前（store）。policyは、APIで取得する |
