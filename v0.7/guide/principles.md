# 基盤の考え方と責任分界

基盤の設計の考え方を、約束として示します。約束しないことも、あわせて示します。アプリを作る前に、ここで責任の分け方を確認してください。

## 基盤が約束すること

### 権限は、基盤がリクエストごとに判断します

基盤は、すべての要求で、その時点の権限（本人はMFAを含む。serviceは承認された範囲）を確認します。アプリが、権限を決めたり、広げたりすることはできません。ヘッダーで、別の利用者や役割を名乗ることもできません。

約束しないこと: アプリの画面の表示制御を、基盤が代わりに行うこと。

### 人もAIも、同じ権限の仕組みで扱います

AIエージェントが、本人を支援して操作するときも、本人の権限を超えられません。MCPのツール名や`readOnlyHint`は、権限の付与ではありません。

AIには、人より厳しい制限がかかることがあります（提案を経由する、停止される、AI専用のレート上限など）。該当するエラーは、[エラーと再試行](https://mxd2024.github.io/claudia-partner-docs/v0.7/errors.html)にあります。

約束しないこと: AI側の設定で、権限が広がること。

### 更新は、競合を検出し、二重に実行されないようにできます

更新と削除には、取得した版を指定します。他の更新と競合すると、412で知らせます。再送キー（`Idempotency-Key`）または`attempt_id`に対応する操作では、通信が途切れても、同じ操作を二重に実行せずに、結果を確認できます。対応しない操作と、その確認の方法は、[共通ルール](https://mxd2024.github.io/claudia-partner-docs/v0.7/concepts.html)の「再送の方式」にあります。

約束しないこと: 競合を、基盤が自動で解決すること。

### 画像は、管理された原本、または外部の原本への参照として扱います

アプリが送った原本は、基盤が管理します。Dropboxなどの原本は、複製せず、参照として関連付けます。関連を解除しても、外部の原本は削除されません。

約束しないこと: 外部の原本の配置、整理、バックアップ。これらは、原本の管理者が担います。

### 機能は、環境ごとに有効化されます

このドキュメントに載っている機能が、すべての環境で使えるわけではありません。どの機能が有効かは、環境管理者から受け取ります。

### ログイン直後に、短い待ちが生じることがあります

新しくログインした直後は、数秒から十数秒の間、`GET /v1/me`が401（`TOKEN_INVALID`）になることがあります。待機の枠を設けて、再確認してください。この待ち時間の上限は、保証しません。

### 試験提供の間は、仕様が変わることがあります

0.7.0-experimentalは、試験提供の版です。更新の前に、[変更履歴](https://mxd2024.github.io/claudia-partner-docs/v0.7/changelog.html)で差分を確認してください。

## 責任分界

責任は、次の4者に分かれます。

### 基盤（提供者）が担うこと

- 権限の判断（リクエストごと）
- データの保持と版の管理
- 画像の関連付けと配信
- 変更の受付と、結果を確認する手段の提供

### あなたのアプリが担うこと

- 画面と業務のロジック
- トークンとキーの安全な保管（ブラウザーに置かない、ログに出さない）
- 競合、再送、失効のときの振る舞い
- 「権限なし」と「未接続」の区別など、利用者への正確な表示
- 外部に置く原本の管理（原本の管理者と共同）

### あなたの組織の管理者が担うこと

- 利用者と、表の権限の設定（`can_manage_access`。MFAが必要）
- serviceの承認

### 環境管理者（提供者側の窓口）が担うこと

- 接続情報の交付（接続先、client_id、redirect_uri、証明書）
- 機能の有効化
- 問い合わせの窓口（[サポートと窓口](https://mxd2024.github.io/claudia-partner-docs/v0.7/support.html)）

## 提供しないこと・未提供のこと

| 項目 | 状態 |
| --- | --- |
| 全APIサービスのMCP対応 | [準備中] |
| 本人のセッションと組み合わせた画像の利用 | [準備中] |
| Dropboxのフォルダー選択、共有URLの解決 | [未提供] |
| macOSでのMCPのキー保存 | [未提供] |
| バックアップと復旧の保証 | 未確定（保証として扱わないでください） |
| 障害対応の受付時間、SLA、廃止の予告期間 | 未確定（保証として扱わないでください） |

## 状態の読み方

| ラベル | 意味 |
| --- | --- |
| [提供中] | 提供しています。環境での有効化と、権限は必要です |
| [準備中] | 提供に向けて準備中です。まだ使えません |
| [未提供] | 提供していません |
| [環境による] | 環境ごとに有効かどうかが異なります。環境管理者に確認してください |
