# 変更履歴

## 2026-10-04 / 初回公開 / API 0.7.0-experimental

Claudia PartnerのAPI・MCP共通ドキュメントを公開しました。

- 公開API132操作の機械仕様（OpenAPI）と、操作ごとの認可・再送・エラーの説明。
- 認証の入手から最初のリクエストまでの手順（利用者のログイン、service接続）と、環境別のOpenAPIの作り方。
- 共通ルール、表・行の操作、通しの手順、アプリの推奨構成、版と対応状況の説明。
- 取込用MCP 8ツールの導入手順、接続できないときの対処、認可の範囲。
- 開発接続申請の窓口と、依頼メールの雛形。

## 互換性と廃止

experimental契約は変更され得ます。利用版を固定して更新前に差分確認してください。既存v1を自動的にv2へ移行しません。破壊的な仕様変更は別版の資料と移行条件で案内し、既存の版別資料を保持します。正式なサポート期間・廃止予告期間は未確定です。未確定の期間を保証として扱わないでください。
