POST/v2/cases業務表・案件 v2 · workspace.caseCreate

OpenAPI定義ありこの操作へのリンク

案件台帳に新規採番して登録

案件台帳に新規採番して登録。登録された人のaccess tokenと現在権限を検査する。操作固有のMFA・管理権・データ権が追加で必要。 v2はv1と別契約。行所有権・列・所属・現在版を検査する。関連表の一括取引は最大8表・計100行操作で原子的に適用し、親行は既存IDを指定する。

認証

Bearer JWT。主体と現在権限を確認します。

操作別の認可条件

json{
  "actor_types": [
    "human"
  ],
  "authentication": "current_identity",
  "mfa": true,
  "mfa_when_lifecycle_enabled": true,
  "required_capabilities": [],
  "max_authentication_age_seconds": null,
  "external_human_mfa": true,
  "identity_freshness": {
    "checked_age_seconds": 5,
    "reconciled_age_seconds": 60
  },
  "administrative_session_when_lifecycle_enabled": false,
  "resource_checks": [
    {
      "kind": "v2_table_grant",
      "action": "caseCreate",
      "checks": [
        "current_role",
        "expiry",
        "row_scope",
        "field_permissions",
        "membership",
        "closed_row_policy"
      ]
    }
  ]
}

再送と結果確認

json{

  "identifier": "header.Idempotency-Key",

    "本文のversion/schema_version/revision/fingerprint（定義される操作のみ）"
  ],
  "safe_to_repeat": true,
  "result_check": "同じキー・本文・前提版で再送し受領結果を確認する。現在権限も再検査する。競合時は最新状態と利用者の意図を照合し、版だけを置換しない。"
}
