# アプリの画面への埋め込み

社員用アプリなどの画面に、Chat Note を `iframe` で埋め込めます。このページの `chatnote.example.invalid` は説明用の例です。実際の Chat Note の URL は利用開始時にお知らせしますので、実際の値に置き換えてください。

## 埋め込みに使う URL

| 表示するもの | URL |
|---|---|
| ケースのカテゴリ | `https://chatnote.example.invalid/case/<ケース番号>?logo=off` |
| Chat Note 全体 | `https://chatnote.example.invalid/?logo=off` |

- `?logo=off` を付けると、左上のロゴとサービス名を表示しません。`iframe` で埋め込むときに付けます。ブラウザーで直接開くリンクには付けません。
- `<ケース番号>` には、Claudia Partner の基盤のケース番号を指定します。半角英数字とハイフンで2〜31文字、先頭は英数字です。
- ケースの担当者でないユーザーが開くと、参加していないことを示すメッセージが表示されます。
- Chat Note にないケース（基盤にない番号、担当者のいないケース）を開くと、まだ Chat Note にないことを示すメッセージが表示されます。

```html
<iframe src="https://chatnote.example.invalid/case/A-1001?logo=off"
        style="width:100%;height:100%;border:0" title="Chat Note"></iframe>
```

## 埋め込みを許可する URL の登録

`iframe` で埋め込んだ Chat Note は、登録した URL の画面の中にだけ表示されます。アプリの URL を Claudia Partnerサポートにお知らせください。登録が済むまでは、アプリに埋め込んでも表示されません。ブラウザーで直接開く場合は、登録は不要です。

- 登録の単位は「`https://` ＋ ホスト名（＋ポート番号）」です。
- アプリは、Chat Note と同じサイト（同じ登録ドメインの https）に配置してください。別のドメインに配置すると、ブラウザーが埋め込み先でのサインイン状態を保持できないことがあります（特に Safari）。

## サインインの流れ

Claudia Partner のサインイン画面は、埋め込んだ枠の中には表示されません。サインインは次の流れになります。

1. 埋め込まれた Chat Note で、ユーザーが「Claudia Partner でサインイン」をクリックします。
2. ポップアップが開くので、ユーザーがサインインします。
3. サインインが終わるとポップアップが閉じ、枠の中の Chat Note が再表示されます。

アプリ側で特別な処理は不要です。ただし、ブラウザーの設定で、アプリの URL からのポップアップがブロックされていないことが必要です。サインインを中止した場合は、元の画面のまま、もう一度サインインできます。

## スマートフォン・タブレットでの利用

スマートフォンとタブレットでは、アプリに埋め込まず、ブラウザーで Chat Note の URL を直接開いて使います。アプリから Chat Note へリンクする場合は、`?logo=off` を付けずに開いてください。
