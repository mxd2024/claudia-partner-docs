# 場所と、使える人

Chat Note の「場所」（カテゴリ）は、Claudia Partner の基盤（社員・役割・ケースなどの情報を管理するしくみ）に登録した**役割**と**ケースの担当者**から、自動で決まります。それぞれの場所を使える人も、同じ情報から自動で決まります。部署とケースの場所では、Chat Note の中で、人を手で足したり外したりする必要はありません。社外の人ごとの場所や、決まった人だけの場所は、管理画面で作れます（[管理画面での設定](admin.html)）。

## 場所の種類

| 場所 | 中身 | 使える人 |
|---|---|---|
| 部署の場所 | 部署ごとの会話と記録 | その部署に割り当てた役割を持つ人と、全部署を見られる役割を持つ人 |
| ケースの場所 | ケースごとの会話と記録 | そのケースの担当者と、全部署を見られる役割を持つ人 |

- 部署の場所は「部署」の下に、ケースの場所はケースのまとめの場所の下に並びます。画面では、ケースの呼び名（例：「案件」）で表示されます。ケースの場所の名前は「ケース番号 件名」です。
- 各部署の場所に割り当てる役割と、全部署を見られる役割は、利用を始めるときに Claudia Partnerサポートが会社ごとに設定します。変えたいときは、ご相談ください。
- 部署ごとに決めた管理役の役割を持つ人は、その部署の場所で投稿の整理（ほかの人の投稿の編集・削除など）ができます。
- ケースの場所は、ケースと担当者を Claudia Partner の基盤に登録している場合に使えます。

## ケースの場所ができるとき

- ケースの場所は、**そのケースの担当者（または全部署を見られる役割の人）が初めて開いたとき**に作られます。画面で開いたときと、アプリのサーバー（アプリの裏で動くコンピューター）が、API（アプリから Chat Note を使うための窓口）でケースの場所を求めたときです。
- まだだれも開いていないケースの場所は、一覧に出ません。
- 担当者のいないケースの場所は、作られません。
- できているケースの場所で担当者がいなくなったときは、場所と投稿は残ります。それ以降は、全部署を見られる役割を持つ人と、Chat Note 全体の管理者だけが見られます。

## 変更が届くとき

| 変更 | Chat Note に届くとき |
|---|---|
| 役割やケースの担当者を、基盤で変えたとき | 1日1回の写し（基盤の内容を Chat Note に取り込む処理）が行われたあとです。行う時刻は、お使いの環境ごとに決まっています |
| 人がサインインしたとき | その時点で取り込んである情報に合わせて、その人が使える場所を更新します |

- 基盤で変えた内容は、次の写しのあとに Chat Note に反映されます。すぐに反映したいときは、Claudia Partnerサポートにご相談ください。
- 役割を持たない人は、部署の場所を見られません。

## 退職した人

- ケースの担当者として Chat Note に取り込まれるのは、在籍している人だけです。
- 退職した人は、部署とケースのすべての場所から外れます。それまでの投稿は、場所に残ります。

## 守られていること

- サインインしていない人は、何も見られません。
- ほかの人のメールアドレスは表示されません。名前は、基盤に登録した表示名をもとにします。使えない記号は取り除き、16文字を超える名前は短くします。整えたあとの名前が短すぎるときは、決まった形の仮の名前になります。
- その場所を使える人に入っていない人は、ケースや部署の場所を、画面でも API でも開けません。
- 管理画面での設定は、会社の管理者が受け持ちます。Chat Note のしくみは、Claudia Partner が受け持ちます。
