# トラブルシューティングとお問い合わせ

## トラブルシューティング

| 症状 | 対処 |
|---|---|
| サインインできない | Claudia Partner のサインインIDとパスワードでサインインできるかを確認してください。Claudia Partner にメールアドレスが登録されていないユーザーは、Chat Note を使えません。会社の管理者にメールアドレスの登録を依頼してください |
| 埋め込んだ画面で、サインインのポップアップが開かない | ブラウザーの設定で、アプリの URL からのポップアップを許可し、ページを再読み込みしてください |
| 埋め込んだ画面に何も表示されない | アプリの URL が、埋め込みを許可する URL として登録されているかを、Claudia Partnerサポートに確認してください。登録後はページを再読み込みしてください。アプリと Chat Note のドメインが異なると、サインイン状態を保持できないことがあります |
| 閲覧できるはずのカテゴリが表示されない | 基盤の役割とケースの担当者を確認してください。基盤での変更は、次回の取り込み（1日1回）のあとに反映されます。ケースのカテゴリは、担当者が初めて開いたときに作成されます |
| ケースのカテゴリに「参加していません」と表示される | そのケースの担当者になっているかを確認してください。担当者になった直後は、次回の取り込み（1日1回）のあとに閲覧できるようになります |
| ケースが「まだ Chat Note にありません」と表示される | ケース番号が基盤にないか、そのケースに担当者がいない可能性があります。担当者がいなくなったケースのカテゴリは、全部署を閲覧できる役割のユーザーが、カテゴリの一覧から開けます |
| ファイルを添付できない | ファイルのサイズと形式を確認してください。添付できるのは1ファイル50 MBまでで、対応する形式だけです。画像は縦・横とも5,000ピクセルまでです。対応する形式は[使い方](use.html)を参照してください |
| 通知音が鳴らない | 右上の「通知音」がオンになっているかを確認してください。ブラウザーやスマートフォンの設定で音が止められている場合もあります |

## ドキュメントの誤記・質問

このドキュメントの誤記と、使い方やしくみについての一般的な質問は、[公開Issues](https://github.com/mxd2024/claudia-partner-docs/issues)にお寄せください。会社名、実際のデータ、実際の接続先、ID やパスワードは投稿しないでください。

お使いの環境の設定や障害など、非公開の情報が必要なお問い合わせは、Claudia Partnerサポートにお寄せください。

## Claudia Partnerサポート

お使いの環境の設定（部署のカテゴリに割り当てる役割、埋め込みを許可する URL、管理画面の利用の手続きなど）、稼働状況、障害についてのお問い合わせ窓口です。連絡方法は、お使いの環境ごとの取り決めに従います。対応時間と SLA は、このドキュメントでは保証していません。

※ 会話の内容や、実在する人の名前・データを送る場合は、必要な範囲にとどめてください。
