# 困ったとき・お問い合わせ

## よくあるつまずき

| 起きていること | 確かめること |
|---|---|
| サインインできない | Claudia Partner のサインインIDとパスワードで、サインインできるかを確かめてください。Claudia Partner にメールアドレスが登録されていない人は、Chat Note を使えません。会社の管理者に、メールアドレスの登録を頼んでください |
| はめ込んだ画面で、サインインの小さな窓（ポップアップ）が開かない | ブラウザーの設定で、アプリの住所（URL）からのポップアップを許可してください |
| はめ込んだ画面に何も表示されない | アプリの住所（URL）が、はめ込みを許可する相手として登録されているかを、Claudia Partnerサポートに確かめてください。アプリと Chat Note の住所のドメイン（`https://` のあとの、サイトの名前の部分）が違うと、サインインした状態を保てないことがあります |
| 見えるはずの場所がない | 基盤の役割とケースの担当者を確かめてください。基盤で変えた内容は、次の写し（1日1回、基盤の内容を Chat Note に取り込む処理）のあとに反映されます。ケースの場所は、担当の人が初めて開いたときに作られます |
| ケースの場所に「参加していません」と出る | そのケースの担当者でないか、担当者になってから、まだ写しが行われていない可能性があります |
| ケースが「まだ Chat Note にありません」と出る | ケース番号が基盤にないか、そのケースに担当がいない可能性があります。担当がいなくなったケースの場所は、全部署を見られる役割を持つ人が、場所の一覧から開けます |
| ファイルを添付できない | 1ファイル50 MBまでで、決まった形式だけを添付できます。画像は、縦か横が5,000ピクセルまでです。詳しくは[使い方](use.html) |
| 通知の音が鳴らない | 右上の「通知音」がオンになっているかを確かめてください。ブラウザーやスマホの設定で、音が止められていることもあります |

## お問い合わせ

- Chat Note の使い方、場所の設定、はめ込みの登録などは、Claudia Partnerサポートにお問い合わせください。連絡の方法は、お使いの環境で定められた方法に従ってください。
- 会話の中身や、実際の人の名前・データを送るときは、必要な範囲にとどめてください。
- このドキュメントの誤記は、[公開Issues](https://github.com/mxd2024/claudia-partner-docs/issues)にお寄せください。会社の名前・実データ・実際の接続先・資格情報（ID やパスワードなど）は投稿しないでください。
