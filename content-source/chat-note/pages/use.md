# 使い方

## サインインする

1. 会社から案内された Chat Note の URL を開きます。社員用アプリなどに Chat Note が埋め込まれている場合は、そのアプリの画面を開きます。
2. 「Claudia Partner でサインイン」をクリックします。
3. Claudia Partner のサインインIDとパスワードを入力します。2要素認証が設定されている場合は、続けて2要素認証を行います。

※ 埋め込まれた画面では、サインイン用のポップアップが開きます。サインインが終わるとポップアップは閉じ、Chat Note が表示されます。
※ ポップアップがブロックされる場合は、ブラウザーの設定で、そのアプリの URL からのポップアップを許可してください。
※ Claudia Partner にメールアドレスが登録されていないユーザーは、Chat Note を使えません。会社の管理者にメールアドレスの登録を依頼してください。

## ログアウトする

画面右上の「ログアウト」をクリックします。ログアウトするのは Chat Note だけです。共用の PC では、ログアウトしたあとにブラウザーをすべて閉じてください。

## 画面の構成

| 位置 | 内容 |
|---|---|
| 左列 | 「スレッド」「チャット」「ノート」の切り替えと、カテゴリの一覧 |
| 中央の列 | 選択したカテゴリのスレッド・チャット・ノートの一覧。「一覧を絞り込む」に文字を入力すると、表示中の項目のうち、名前にその文字を含むものだけを表示します。本文を検索するときは、右上の「検索」をクリックします |
| 右側 | 開いたスレッド・チャット・ノートの内容と、入力欄 |
| 右上 | 返信通知、検索、通知音のオン・オフ、ログアウト |

スマートフォンでは、一覧が画面の上部に横一列で並び、その下に内容が表示されます。

## スレッドを作成する

1. 左列で「スレッド」を選択し、投稿するカテゴリを選択します。
2. 「＋」をクリックし、タイトルと最初のメッセージを入力して作成します。
3. 返信するときは、一覧からスレッドを開き、画面下部の入力欄に入力して送信します。

※ 入力欄で Enter キーを押すと改行します。送信は Ctrl＋Enter キーです（Mac は ⌘＋Enter キー）。
※ 投稿ごとに「返信」「引用」「編集」「削除」ができます。編集と削除ができるのは自分の投稿だけです。カテゴリの管理役のユーザーは、ほかのユーザーの投稿も編集・削除できます。
※ 古い投稿は「以前のメッセージを表示」をクリックすると表示されます。

## チャットを始める

1. 左列で「チャット」を選択し、「＋」をクリックします。
2. 相手の名前を入力して検索し、相手を選択します。複数人を選択できます。

※ 1人を選択すると1対1のチャット、2人以上を選択するとグループチャットになります。
※ 社員は、Chat Note を使っているすべてのユーザーを相手に選択できます。社外のユーザー（協力会社など）が選択できる相手は、同じ部署またはケースのカテゴリを使っているユーザーだけです。

## ノートを作成する

指示書や議事録など、見出しや表を使って整理したい記録はノートに残します。

1. 左列で「ノート」を選択し、カテゴリを選択します。
2. 「＋」をクリックし、タイトルと本文を入力して「保存する」をクリックします。

| 操作 | 方法 |
|---|---|
| 見出し・太字・箇条書き・表 | 入力欄の上のボタンで挿入します |
| 2列の表にする | 項目名と内容が1行ずつ交互に並んだ部分を選択し、「選択した行を2列に」をクリックします |
| コメント | 開いたノートの下の欄に入力します |

## ファイルを添付する

「＋ 添付」をクリックするか、入力欄にファイルをドラッグ＆ドロップします。画像は貼り付けもできます。

| 項目 | 内容 |
|---|---|
| ファイルサイズ | 1ファイル50 MBまで。縦または横が5,000ピクセルを超える画像は添付できません。大きな画像は縮小して表示します |
| ファイル形式 | 画像（jpg・png・webp・gif）、動画（mp4）、PDF、Word・Excel・PowerPoint（doc・docx・xls・xlsx・ppt・pptx） |

## 返信通知と未読を確認する

- スレッドやノートの自分の投稿に、ほかのユーザーが返信または引用すると、右上のベルのアイコンに件数が表示されます。クリックすると一覧が開き、「すべて既読にする」をクリックすると件数が消えます。
- 特定の投稿への返信・引用ではない書き込みと、チャットのメッセージは、ベルのアイコンには表示されません。チャットの未読は一覧の未読マークで確認します。
- 右上の「通知音」をクリックすると、通知音のオン・オフを切り替えます。
- 一覧は、更新が新しい順に並びます。
